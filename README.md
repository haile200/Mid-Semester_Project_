# My Beta study guide (GitHub Pages)

This branch holds only the interactive study-guide website for the My Beta project; the project code lives on `main`.
Live site: https://haile200.github.io/Mid-Semester_Project_/
Plain HTML, CSS and JavaScript with no build step: open `index.html` directly, or serve the folder.
To update: edit the files, bump the `?v=` numbers in `index.html`, commit and push this branch.
